## How to sign

To sign this agreement, post the following sentence, exactly as written and with nothing else in the comment, as a comment on your pull request:

> I have read the CLA Document and I hereby sign the CLA

A bot checks pull request comments for this exact sentence and records your signature automatically; no other action is required.

The commits in your pull request must be linked to your GitHub account (for example through a verified email address or your GitHub no-reply address). Commits from an email that is not linked to any account cannot be matched to a signature.

If you signed an earlier version of this agreement, the bot will ask you to sign this version on your next pull request.

## Signature records

Signing records, in a file committed to the public git history of this repository on the dedicated `cla-signatures` branch: your GitHub username, your numeric GitHub user ID, the ID of your signing comment, the time of your signature, the repository ID, and the pull request number. Because git history is effectively permanent, this record cannot be fully removed once committed. See [`PRIVACY.md`](PRIVACY.md) for further disclosure.
